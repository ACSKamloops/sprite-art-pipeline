## Concrete unresolved categories

1. **Complete command grammar and editing semantics.** The missing structured
   suffix still leaves unknown-field rules, nested validation, discriminator
   payloads, `patch_command` indexing and its `expect` encoding unresolved. The
   nine-row table closes the documented primitive inventory, not the complete
   handler schema. Local plan, raster and construction dialects must keep their
   own names and versions.
2. **Missing craft and inspection routes.** The absent local commands are
   `explain`, `clusters`, `reveal`, `sweep`, `score`, `extract-palette`, `repair`,
   `shade`, `selout`, `reoutline`, `clean-lines`, `aa`, `mirror`, `cluster` and
   `palette`. An indexed palette editor does not reproduce ramp generation;
   an outline operator does not reproduce reoutline; a coordinate flip does
   not reproduce node mirror/bake. Several of these commands have undisclosed
   heuristics, so an explicit local algorithm would be a substitute.
3. **Family-specific build adapters and runtime closure.** Generic stage prose
   remains in some feature records. Preparation, target identity, submission,
   polling/progress, result extraction, native cel commit, clocks, cancellation,
   retry and finalization need their actual per-family branches. Browser,
   Godot, Lua, REST and MCP paths cannot be silently collapsed into one runner.
4. **Unobserved native, browser and export behavior.** Native indexed host undo
   parity, original Worker/GPU/bootstrap behavior, complete VFX constructor
   coverage beyond the supported 17-family renderer, and complete video/PTS
   checks remain open. Local RGBA ASE exchange and local Godot checks establish
   their declared subsets. A browser selecting an image URL by elapsed time is
   not proof that every decoded frame was displayed on time.
5. **Backend comparison preparation.** There is no implemented private model
   backend or configured original-art comparison action. A versioned protocol,
   frozen input/baseline selection, exact expected outputs, review questions,
   resource limits and negative cases must exist before comparing backends.
   The newly documented normal-map interface supplies no local estimator.
6. **Actual character construction and animation acceptance.** A coherent
   editable humanoid, missing surfaces/views, registered directions, strong
   action poses, grip/contact/weight checks, animation-event requirements and
   complete timed visual inspection remain unaccepted. Passing editing/history
   tests or viewing mechanical markers does not approve these assets.

## What is controllable locally now

The loopback controller exposes real supplied-art operations. The UI can upload
PNG/APNG or project JSON; open immutable sequence/project/history artifacts;
edit existing unlocked cels with guarded pencil/erase strokes; preserve/select
palette indices and add RGBA colors; set frame ticks; move history cursors;
preview and render supplied animations; inspect stored records and schemas;
save a declared plan without executing it; and submit/poll/cancel/retry local
jobs. Registered library methods and additional deterministic operations are
available through explicit method requests or declared plans.

The interface is **not yet a complete graphical animation-authoring studio**.
It does not author missing cels, layers, rig anatomy or hidden surfaces through
its canvas controls, provide a graphical pose/track editor, infer high-quality
motion, generate an image or invoke a private vendor handler. Plan JSON and
method schemas expose engineering controls, not completed versions of every
analyzed vendor feature.

Readiness is evaluated by the backend, with the original inventory identities
pinned independently. Missing rows, optimistic summary flags, incomplete
grammar or partial flows do not open comparisons. Setup diagnostics establish
environment and supplied-art mechanics on the tested source fingerprint only.
Both the UI comparison control and HTTP comparison route remain unavailable.

## Accessible work versus unavailable evidence

Useful next work can proceed without art experiments: finish exact retained
source branch accounting; specify versioned local grammar/primitive adapters;
implement missing routes where a declared local policy and independent oracle
are possible; broaden per-family deterministic preparation/finalization and
failure controls; validate remaining codecs/clocks and original browser/native
paths against permitted retained inputs; and freeze the eventual backend
comparison protocol. Each task should close named obligations with evidence,
not merely add another passing generic recipe.

The omitted hosted grammar requires a complete permitted documentation/schema
source or separately scoped runtime evidence. The 24 runtime questions need
controlled observations of the relevant target, including failure branches.
The 21 server-disclosure questions cannot be answered by repeating client
decompilation: private weights, training data, hidden prompts, neural kernels,
server scheduler/persistence or current hosted implementation require released
artifacts, provider disclosure or a revised explicitly local reconstruction
scope. Paid access and credentials alone do not expose those internals.

It would therefore be inaccurate to promise that all original full-vendor
questions can be completed from the files currently available. The honest
deliverable is a precise gap ledger plus implemented, verified local substitutes
whose boundaries are explicit. Changing that scope requires an explicit
decision; it cannot happen by relabeling unresolved rows as complete.
