## Highest-value next discriminators

These are proposed evidence requirements, not authorized submissions. Prefer offline source/replay and retained data first; freeze predictions, stop criteria and budget before any future request.

1. **Private alpha:** do not repeat a generic background/flood example. Corrected Simple/Complex already differ at 89 pixels and the nearest host/flood candidate has a one-pixel counterexample. A useful new test changes only an enclosed pocket, diagonal connection or boundary color at that recorded counterexample, with exact regional alpha/RGB predictions from a specified candidate. It can narrow standalone route behavior, not prove the animation matte. For animation, seek the *same bound native frames* before/after segmentation, or an independently controllable deterministic postprocess route. Two fresh stochastic generations cannot isolate matte changes. [Connectivity findings](../recovery-next-20261014/CUTOUT-CONNECTIVITY-FINDINGS.md), [route trace](../recovery-depth-20261014/PIXEL-CONVERSION-RECOVERY.md).
2. **High-K/automatic palette:** first make a constructor predict the three existing pale-family misses without per-family patches; ordinary rounded-center refinement already fails. Then freeze an equal-histogram K32 order/permutation fixture with tied frequencies, and a genuinely new interacting-color holdout that distinguishes initialization/rounding hypotheses. Low-K AB/BA duplication and reused warm/green colors are not that holdout. A separate automatic-K fixture must predeclare expected count/order as well as full RGBA. Retain hidden RGB and actual strip independently; stripping hidden-only entries can destroy full-RGBA replay. [Float assignments](../recovery-round3-20261014/PALETTE-INFERENCE.md), [hidden strip failures](../recovery-round3-20261014/HIDDEN-PALETTE-REVIEW.md).
3. **Positive-strength dither:** more scalar amplitude grids cannot fix the existing exact empty intervals. Any candidate must first survive all retained strength/phase witnesses offline. If source remains unavailable, one spatial-permutation/changed-width diagnostic using identical RGB+phase keys can distinguish traversal/cache/context hypotheses not excluded by the old rows; include known equal-sum counterexamples and freeze phase alignment. It will not by itself identify a general multi-color rule. Tiny positive strength already differs from nondithered mapping by 1,591 pixels per frame; do not rediscover that branch observation. [Independent characterization](../recovery-next-20261014/DITHER-INDEPENDENT.md), [exact interval falsifications](../recovery-round3-20261014/DITHER-INTERVALS.md).
4. **Motion, sampling and deflicker:** immediate useful work is offline: inspect every native neighbor and wrap, annotate actual gear/contact landmarks, test a declared cut at equal source times, and separately accept/reject its art. To infer private sampling/deflicker, obtain stage-corresponding native/intermediate/postprocessed bytes and effective settings from the *same job*. Twenty identical main/quantized pairs expose no changed animation stage; a larger reported original-color count cannot supply missing pixels. Threshold changes across separately regenerated clips remain confounded. A controlled synthetic-video postprocess input would be valuable only if a real authorized interface admits it; no such endpoint is assumed. [Paired-stage evidence](../recovery-next-20261014/PAIRED-COLOR-RECOVERY.md), [H3 source/clocks](../recovery-depth-20261014/WEB-MODEL-RECOVERY.md).

## Does progress require PixelLab access or private weights?

**No, not for every remaining observation.** Client source execution, bounded grammar/tool recovery, browser decode conformance, receipt correctness, export preservation and artistic review can progress offline. Additional public disclosures or shipped code could resolve rules without paid calls. Non-neural private palette/dither/cutout behavior might admit a faithful bounded behavioral model without possessing weights, but that requires independent predictions and explicit counterexamples; it does not establish source identity.

Fresh statements about an unobserved server response require an authorized service oracle or equivalent disclosed source/stage data. Paid black-box calls can falsify a candidate, demonstrate finite equality and reveal a response contract. A finite set cannot uniquely identify arbitrary internals, prove universal parity, recover absent intermediate bytes, establish exact deployed weights, or make stochastic comparisons causal. Some needed evidence may simply not be exposed by the public API; spending more credits cannot manufacture it.

For independently reproducible private **generation**, the missing essentials may include licensed weights or a stable accessible backend, revision identity, preprocessing, effective prompts/conditioning, sampling/random-state rules and postprocessing. Exact weights are not logically necessary for a finite matched-output observation or for using a remote service; a disclosed family label such as MiniMax H3 is nevertheless insufficient for an independent equivalent generator. Private grammar/state/service requirements likewise need their own source or controlled runtime evidence, not model weights by default.

The honest completion target must therefore be explicit: bounded client-source reproduction and reliable local asset handling are attainable and already evidenced in selected paths; broad behavioral compatibility needs broader independent conformance; private implementation/model identity and whole-product parity remain open. None of the 63 catalog requirements should be marked closed solely because one subflow now executes original code.
