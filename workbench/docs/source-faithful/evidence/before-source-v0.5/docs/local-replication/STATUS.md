## Readiness and execution

| State | Meaning | Does not establish |
| --- | --- | --- |
| `setup_ready: true` | A retained setup proof passed the required environment, eleven diagnostic recipes, editing/native exchange and fresh-Store checks for the current package source fingerprint | Complete analysis, a working generative backend, private vendor parity or approved artwork |
| `comparison_ready: false` | Original requirements, grammar, complete command/flow implementations and backend prerequisites still hold comparisons | Failure of the independently available supplied-art editor or mechanical diagnostics |
| Job dispatch completed | The controller accepted/completed the local request | The returned asynchronous job succeeded or its output passed visual review |
| Candidate/technically verified | The named local operation and declared technical checks completed | Gameplay, identity, anatomy, contact or9/10 animation quality |

The pinned baseline prevents dropped/renamed requirement, command, flow or grammar rows from opening the gate. A selected source answer cannot close a record whose whole-question flag remains false. Source changes invalidate setup evidence and require a controller restart before verification or queued plan execution. [Independent gate review](../readiness/GATE-REVIEW.md) and [controller review](../readiness/WEB-CONTROLLER-REVIEW.md) preserve initial failures and corrected checks.

The current browser URL is `http://127.0.0.1:8874`; the canonical local command is:

```bash
.venv/bin/python -m sprite_workbench --workspace workspaces/web-control/store web \
  --base-dir workspaces/web-control/files --port 8874
```

Do not start a second manager against that same Store. Use a separate Store and port for another controller. Browser file operations remain inside its base folder; the separate trusted CLI/JSONL channel retains broader local filesystem access. No provider forwarding or public hosting is configured.
