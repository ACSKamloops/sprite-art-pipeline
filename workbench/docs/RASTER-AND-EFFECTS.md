# Exact edits and recovered effects

`raster.apply_edits(layers,changes,protected=None)` uses the disclosed seven-operation ordering with one-based frames and zero-based inclusive regions. Mutating masks are opt-in; selectors read current values and are then frozen; copy and outline geometry read the pre-list snapshot. Every submitted patch coordinate/color validates before mask exclusion. The local implementation rejects touched trusted protection even for identical writes. It preserves arbitrary decodedRGBA, including partial alpha; that is an explicit local extension to the documented binary-alpha restrictions of some target paths.

The local polygon selector uses even-odd pixel centers, offset rectangles clip, outlines use orthogonal grow/erode, and brushes have right/down even-size bias. These choices are versioned local policies where private handler edge details are unavailable. Unsupported outline/draw/craft algorithms do not silently run under vendor names. Crop/paste guards bind the complete source raster ID, region, node and pixel hash in the `local-crop-v1` dialect; they are stricter than the observed target crop-only fingerprint.

`effects.render_effect(store,recipe,subject=None,images=None)` runs pinned, hash-verified original factory slices in an offline Node adapter. It supports the recovered17 procedural layer families and explicit fully specified recipes, not arbitrary expansion of105 catalog names. Its original parser/renderer is the reference implementation; running the same source is not an independent proof of its artistic quality or current remote MCP identity. There is no browser Worker/thread/CSP simulation claim. The local default resource profile limits sides to512,32frames,128layers and60seconds. No backend URL is fetched.

Frame/back/front streams enter the same immutable sequence store with rational1/fpsholds, original recipe IDs, renderer digest and binary-alpha policy. They can then use the same revision, review, library and exporter services as imported or layered artwork. New output remains an unreviewed candidate.
