# Local-v1 module integration contract

This is our implementation API, not a recovered PixelLab API. Python3.11+ with NumPy/Pillow, a package `sprite_workbench`, and one persistent workspace. CLI, local viewer and tests use the same services.

`Store(path)` owns `blobs/`, immutable JSON documents and `state.sqlite`. `put_bytes(bytes)->sha256`; `get_bytes(id)->bytes` verifies identity. `put_json(dict)->id` / `get_json(id)->dict` use canonical JSON. `put_raster(np.uint8[H,W,4])->id` / `get_raster(id)->array` preserve all rawRGBA including hiddenRGB. `set_head(name,id,expected)->bool` is transactional compare-and-swap; `get_head(name)->id|None`. IDs are SHA256 digests, never filesystem paths. Content artifacts may be orphaned candidates; publication is a separate guarded operation.

`save_sequence(store, arrays, durations=None, pivots=None, loop=False, directions=None, metadata=None)->id` creates immutable `kind=sequence` data. `durations` are `Fraction` seconds (default1/12); `pivots` are `(x,y)` canvas coordinates (default0,0); direction labels are explicit (defaultunspecified). Each frame stores raster ID, rational `[numerator,denominator]` duration, pivot and direction. `load_sequence(store,id)->(document,list[array])`. Equal dimensions, nonempty frames, positive durations and finite pivots are mandatory. Duplicate frames/holds are retained.

`ValidationError(ValueError)` and `UnsupportedCapability(ValidationError)` are structured local failures. Construct the latter as `UnsupportedCapability(capability, reason)`; `.capability` and `.reason` are strings and `.to_dict()` provides a JSON error. No private endpoint may be forwarded or silently emulated. Backend capabilities distinguish `supplied-art`, `deterministic-source`, `local-substitute`, `unsupported` and later actually available model adapters.

Root owns `core.py`, `raster.py`, `effects.py`, `cli.py`, end-to-end integration tests and the local viewer. Raster methods return new arrays; failed guards never publish heads. Effects run the pinned recovered offline JS renderer with resource limits and immutable recipe/source hashes.

Preparation owner implements `prepare.py`, `pose.py`, `terrain.py`, `assets.py`, tests and source-binding docs. `prepare_request(adapter, images, options)->dict` returns prepared immutable descriptors/arrays and ordered operation records; no call to models. Projection API `project_pose(joints, direction_degrees, tilt_degrees, profile)->list[dict]` returns labeled source-specific coordinates/depth. Terrain accepts explicit supplied cells/connectivity; font accepts an explicit local font file; vocal accepts explicit viseme rasters.

Geometry owner implements `scene.py`, `export.py`, `review.py`, tests and docs. `render_scene(store, scene)->sequence_id` takes canvas, owned raster/mask nodes, parent/anchor transforms, supplied keyframes with explicit durations and direction, and source-hash bindings. No hidden-surface or missing-pose inference. `export_sequence(store,id,directory,formats)->report` writes exact framePNGs, sheet/manifest, rational timelines, explicitly bounded GIF/APNG, editable local layered data, review packets and Godot assets. `review_sequence(store,id,directory)->report` includes all ordered adjacent/loop pairs, exact diagnostics and correct-clock local playback; numeric scores do not award visual9/10.

Transport owner implements `jobs.py`, `library.py`, `capabilities.py`, tests and docs. `JobManager(store,workers=4)` executes named local handlers with deep-frozen input identity, bounded admission, cancel/quarantine and stale-publication guard. Library stores immutable named candidates/states/directions and uses explicit candidate IDs, preserving per-direction sequences. Capability registry accounts all111 public operations/101 captured MCP definitions with schema/source identity and an explicit local equivalent or unsupported boundary. No credentials, external network or inferred model availability.

Tests are whole-flow contracts (F01–F11) and independent discriminating oracles. Each module supports its supplied-art/deterministic subset and exposes the inaccessible learned branch explicitly. A test result cannot claim that an unsupported branch ran. New image/model experiments wait until enclosing flows are ready.
