# Reproduce the current get-up from saved raw paint

This study retains the actual built-in OpenAI ImageGen prompt, ordered reference
images, raw returned image, source ownership maps, literal bookends and guarded
support-key edit journal. It accompanies the latest selected ten-key SE get-up.
It does not make another model call or promise a fresh generation will match.

From the repository root:

```bash
.venv/bin/python examples/current-hero/replay_recovery.py \
  --output output/my-recovery-replay
```

The output must be fresh. The command checks the saved inputs, replays the raw
image sampling, adds the two source-part keys and compares all ten RGBA frames
and rational holds with the selected public character. It then exports PNGs,
atlas, editable project, ASE and exact APNG through the normal bank exporter.
It needs Pillow and NumPy, the sibling pipeline toolkits and no original
workstation or provider credential. It replays frozen maps; it does not infer
new ownership masks for a different image.

## Actual operations

1. `inputs/appearance.png` supplies identity/style; `inputs/geometry.png`
   supplies six connected poses; `inputs/entry-exit.png` supplies context only.
   Their order and roles are in `prompt.txt`. The source guide uses Quaternius's
   CC0 `LayToIdle`, with an authored Head-scale change and fixed camera. See
   `recipe.json` and `guide-LICENSE.txt`; the source GLB is not bundled.
2. `raw.png` is the actual1024×1536 return, not the requested1280×1920 size.
   It has partial alpha and a crown crossing a nominal512px cell boundary.
   The original generation receipt retains its historical cache path as
   provenance; the replay reads the bundled raw image instead.
3. Six frozen full-image owner/sample maps use the original cell origins and
   one0.90 scale about native pivot(40,72). Alpha200 was chosen after comparing
   the actual halo. Retained source samples become opaque. This explicit
   overscan recovers the crown and excludes it from the neighboring character;
   there is no independent bbox fit/recenter for each pose.
4. The.725s support key keeps complete boots and shifts the complete upper
   (+2,-4), with connected source trousers. `maps/transfer-xy.npy` records every
   source address; `transfer-kind.png` labels background/boots/trousers/upper.
   No new hidden cloth is claimed. `transfer-method.json` describes the authorship.
5. The1.0875s settle uses the skill's frozen source-settle fixture. The complete
   upper moves(-3,+2), the entire lower body from row53 remains exact, and only
   the waist band deforms. An earlier leg-deforming version was rejected.
6. The literal downed/neutral images bookend the final ten exposures, totaling
   1.2 seconds. `recipe.json` retains the exact holds. ASE integer-ms preview
   timing rounds the two62.5ms exposures to63/62ms; the manifest stays authoritative.

The source masks and coordinates apply only to this exact saved raw input.
For new paint, inspect the return and author/verify new masks; do not reuse a
stale map or use the source guide as proof of model pose compliance.
