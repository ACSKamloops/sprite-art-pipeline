# Sprite construction contract v1

Root owns integration, study/example art, evidence runbook and installed skills. Core worker owns `sprite_lab/`, `scripts/sprite_edit.py`, `tests/`, `docs/editing-contract.md`. Native worker owns `native/`, including golden fixture producer/independent audit and examples. Editor worker owns `editor/`, vanilla static HTML/JS/CSS UI and browser checks. Each has its own branch/worktree; communicate dependencies and cherry-pick reviewed commits into root.

Project JSON schema `sprite-edit-project/v1`: `canvas` contains integer `width`,`height`, `render_pivot` and `ground_pivot` as two-element coordinates; `palette` is RGBA byte arrays with entry0=[0,0,0,0], allows modern art with arbitrary RGB colors (no 16-bit palette restriction). `layers` is an ordered back-to-front list of {id,name,locked}; `cels` is object keyed stablecelID, each {layer_id,pixels:[palette_index,...]} with full-canvas dense row-major pixels. `frames` list {id,duration_ticks,cels:{layer_id:celID},landmarks:{name:[x,y]}}. `animations` list {id,frames:[frameID,...],fps,loop,events:[{at_tick,name}]}. `provenance` arbitrary documented source hashes/conditions/limits. Preserve source and live project distinct. Missing cels are transparent. No per-frame automatic recentering.

Precise edits are JSON transactions with `schema`, `expected_project_sha256`, operations and reason; core defines canonical JSON SHA256 and operation schema then messages editor immediately. Required paint/stroke, erase, masked replace-color, translate cel/layer, palette edit, immutable timing/pivots unless explicitly edited, undo/redo replay and localization diff. Candidate AI patch may be imported only through allowed mask with before/after/outside-mask invariants. Invalid transactions leave original unchanged. History stores full preconditions and exact results. UI/browser and Python produce same pixels/project serialization for fixture operations.

Exports: deterministic RGBA PNG frames/atlases, frame/event manifests, lossless editable project JSON and at least one actual layered editor exchange (ASEPRITE/ORA), source receipts and exact diff reports. Full native golden comparison checks actual independent pixels/coordinates/order/clock, not only internal hashes. Art quality gates separately inspect intended-scale temporal motion, alternation, silhouette, contact/attachments, seams, legibility; passing schema does not approve art.
