## Reproduce

Python3 + Pillow, no generation API required:

```sh
python build.py --samples 72 --output fresh-dense
python contact_probe.py --pack fresh-dense --output fresh-contact
python verify.py
```

Outputs refuse existing directories. `verify.py` checks the frozen dense-v15 candidate and renders a fresh private72-pose run. To edit, change explicit anchors/parts in design or gait parameters/tracks in clips, produce NEW output, and bind fresh contact/art reviews. The twelve-key inspection build is available without `--samples`; its fractional7.2/3.6 tick holds are not the final game bake.
