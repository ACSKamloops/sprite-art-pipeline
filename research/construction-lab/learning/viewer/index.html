What this teaches our authoring pipeline

Keep body poses, equipment, frame holds, root movement, palette changes, projectiles and gameplay events distinct. Reproduce each with the same start state and input sequence, then compare both state and displayed frames. A still sprite supplies one view; other views and hidden anatomy need additional drawings, key poses or geometry.
