# MW4 mech-only Blender handoff

Start with [BLENDER_HANDOFF.md](BLENDER_HANDOFF.md). Open `blender/atlas.blend` for a static mech with packed textures and embedded notes, or choose another of the 113 groups in `inventory/library.json`. GLB and OBJ exports are also included.

This package contains original mech geometry, textures, joint metadata, and native pose/animation files, plus converted OBJ and GLB previews. Native animations still need conversion into Blender actions. The preview hierarchy uses rigid parented objects, not an armature rig.

The original source game ZIP and the extraction workspace are retained separately from this portable handoff.
