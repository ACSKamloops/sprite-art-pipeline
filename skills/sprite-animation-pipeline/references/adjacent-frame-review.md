# Dense animation review and supported transitions

Use fixed-canvas predecessor/current comparisons for **every tick**, including loop last-to-first. Separate a deliberate one-shot replay reset from a playable state transition. Preserve the full PNG canvas in the display; a previous cropped review hid weapon tips even though its scalar metrics used full images.

The companion construction toolkit includes `qc/temporal/audit_pairs.py`, `verify_review.py` and `transition_contract.py` (Python/Pillow/NumPy). The audit binds source, manifest and RGBA/file hashes, computes silhouette/material/joint/grip changes, and makes native predecessor/current, overlay and difference sheets. Large deltas are review requests, not automatic anatomical failures. Shared colors and foreground occlusion make material area changes legitimate in some poses. Bind every viewed sheet and pair ID in a fresh review receipt; the completeness gate also requires the actual loop/reset/state comparisons, so deleting both evidence and its review claim cannot pass.

An equipment-aware game needs matching ready, locomotion, attack and interrupted/recovery poses. A clip inspection export can use its authored default gear, but those defaults do not define playable transitions. The tested example uses persistent selected gear, explicit inventory equip/stow, weapon-gated attacks, and equipped hurt/fall/recover. The first exporter omitted interrupted states and would have visibly removed the weapon. A state contract names the actual controller hash, equipment states, supported exact bindings/endpoints and transition policy. Never substitute unarmed idle when an equipped direction variant is missing. Pose blending is a separate capability: the current sandbox uses hard pose changes while preserving its physical root and locomotion phase.

For actual playback, use `pilot/review-player` in the construction toolkit. Serve the toolkit root locally and select `?pack=../rigged-character-v2/generated/`. It verifies source files and decoded PNG hashes, exposes native/2x/3x display, predecessor/difference/onion skins, step, pause and explicit replay. A completed one-shot remains completed when Play is pressed. Match the source's 60Hz held-frame clock; pause must freeze both time and pixels.

Timed browser captures can establish that source frames were displayed in sequence and let an image-capable reviewer inspect chronological samples. Retain wall time, source ticks, canvas readbacks and start/end source fingerprints. A recorded video alone is not proof the reviewer watched it continuously. Supply the local player and an exact-tick MP4 reel for human viewing; GIFs are previews with quantized durations. The reel labels/separates independent clips rather than pretending they are gameplay transitions.

Adversarial reviewers should check native-size readability, gear attachment, palette/material consistency, floor penetration, hidden-joint branch changes, authored holds, and supported action/interruption seams. The current case caught a knife-shaped blaster, cast elbow branch jump, equipped fall gear disappearance, and a sword guard two pixels below the floor despite valid atlas hashes. Re-render repairs and bind a new receipt; keep rejected source/exports/reviews. Engineering checks and art decisions stay separate, with explicit coverage and unresolved findings.

Hash equality can preserve observations, but never lets a historical whole-pack approval masquerade as a fresh approval.
