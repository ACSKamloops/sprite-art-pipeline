# Continuous motion guide to painted sprites

Use this when a good character drawing needs motion and an image/video generator can accept references. This is an authored control workflow, not recovery of a vendor's private weights or inference implementation.

1. Freeze the character reference, intended native painted height, canvas, camera and action/view. Reserve motion margins. A source that fits does not guarantee generated extremes fit.
2. Author or recover a continuous motion source. Distinguish source joints from newly authored mechanics. For grounded walking, keep physical root, actual shoe shape, heel/flat/toe stages and contact targets explicit; a single ankle endpoint cannot encode shoe pitch. Check reach, nonpenetration, rigidity and periodic root translation. Inspect a full-body proxy before generation: mathematically grounded motion can still crouch or march.
3. Choose a transport that carries the necessary controls. An18-joint skeleton lacking heel/toe fields does not transmit a complete shoe. A rendered reference video carries visible shoe geometry, with empirical adherence. Retain source pins, renderer settings and actual presentation times. Exact periodic root-relative geometry can justify reusing rendered cycles; report unique renders separately from timeline frames. Match the current provider's documented input limits.
4. Bind appearance and motion references separately. Record the literal prompt, ordered images/video, model fields actually exposed, one-call authorization and actual response. A prompt that says preserve legs does not prove preservation. Do not retry an ambiguous paid submission.
5. Retain the complete native return and actual PTS. Requested duration and rounded container duration are not authoritative frame timing. Derive rational holds from timestamps and final sample duration. A separately named first-cycle candidate may select an explicit source window; retain every omitted source frame and review the actual wrap. Recurrence metrics alone do not certify a seamless loop.
6. Use one common canvas transform. Preserve raw alpha before conditioning. For model references, a separate copy may zero RGB only beneath fully transparent pixels; verify all alpha and visible RGBA remain exact. Hidden green RGB can appear in an RGB-only preview even when alpha is zero. Never silently change the authoritative source to accommodate a preview.
7. Separate geometry, color, timing and performance edits. A green-fringe treatment is valid only where the intended costume permits it; journal every changed value, preserve alpha and unrelated channels, and inspect contrasting backgrounds. An upper-body semantic redraw can also change boot size, placement and overlap. Re-audit the actual result rather than inheriting previous contact or pose approvals.
8. Compare complete cycles at native scale and rational timing. A fixed atlas-row registration can remove a demonstrated layout offset yet leave a poor gait. A timing-only experiment can preserve every pixel yet have no confident perceptual benefit. Retain those outcomes and use the case-free review card for anonymous assessments.
