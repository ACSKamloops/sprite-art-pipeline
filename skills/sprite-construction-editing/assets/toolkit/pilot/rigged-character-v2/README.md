# Original four-view example

Read the skill reference `four-view-workflow.md` for build/test/review commands. Authoritative source is design/clips/rig, retained with its original API. The included renderer uses continuous 2D contours, rigid parts and analytical two-bone IK; front/back are authored planar views and left mirrors right. No generated pack or historic acceptance receipt is supplied: produce a fresh bake and measured cache, then perform fresh mechanical and visual review.

Persistent gear must be explicitly selected. Default clip-declared gear is inspection-only. Equipped idle/walk/run/hurt/knockdown/recover have sword/blaster variants; cast/celebrate require explicit stow. The example currently supports 96 bindings,6000 held 192px frames at60Hz. Front/back depth/foreshortening remains prototype quality; hard controller transitions do not implement pose blending.
