# Recovered pose controls and generated paint

Use when a shipped client supplies motion templates and a remote or image model supplies the drawing. Keep three separate authorities: source motion data, character-specific retarget/calibration, and the rendered pixels. None implies the other two are correct.

## Recover the actual control path

Read the catalog, loader, projection, reference-body calibration and request constructor. Pin their bytes. Execute original client functions in an isolated host when feasible; pin the host substitutions too. Do not import an analysis helper with top-level output writes merely to call one math function. An independently extracted pure function can be useful, but label its execution separately from actual original-client execution.

The retained PixelLab case selected realistic walk8 `[3,7,12,16,21,25,28,34]`, with all flip flags false. Its loader also defines flips as z reflection plus LEFT/RIGHT label exchange. The catalog establishes order, not physical timing. A numbered file absent from the catalog/folder is not a missing pose to invent. The 18-joint data supplies ankle-like LEG points; it supplies no heel, toe, sole plane, world-contact labels or source frame holds.

The recovered Lua uses a centered orthographic projection with camera rotation/tilt, derives a shoulder-midpoint neck and supplies ordinal depth ranks. Original-client depth and another runtime's raw z need not have identical conventions. Keep ranks as ranks rather than inventing metric camera depth. In the retained south-east test, the camera was315°/20°; these are case settings, not universal correct values.

Bind the reference pose to the actual reference image. A prior successfully submitted image/pose pair establishes provenance, not anatomical ground truth. When changing template family/count, keep a single declared reference-body calibration across every target. Preserve original rounding/clamping and labels. Verify full label completeness and near-edge joints before spending on a remote request. A documented `fixed_head` coordinate option is not a guarantee of unchanged face pixels in a neural redraw. Likewise, the remote API having no mask/freeze field matters to expectations.

## Retarget to painted parts without confusing their anchors

Distinguish patella, boot cuff, ankle, painted material center and an implementation's misleading field names. In this case an old `knee` variable was a cuff target; the source cap's painted center lay three pixels above its warp origin. Mapping a real template KNEE to that cuff produced the wrong visible joint even with correct source math. Pin both source and destination anchors, bone gains, occlusion order and newly drawn underlaps.

Generated or recovered joint motion does not establish a convincing shoe orientation. Author foot pitch and heel/toe witnesses separately when absent from the source. A fixed upper cutout can preserve identity yet fail to convey weight transfer. The eight-pose case following the recovered catalog received an independent6.4/10 overall, animation5.6: compressed passing legs, weak support transfer and rigid upper assembly remained. A discriminating follow-up is one compact passing pose, with a single-cell guide, explicit knee/ankle positions and a separate material reference. Register the whole canvas/grid once and retain that transform. Do not individually bbox-fit the poses to conceal drift. When preserving a canonical upper body, import lower paint with explicit source-owned masks and review the complete seam and overlap. Exact preserved pixels cannot repair incorrectly attached new legs. Establish both opposing leads and readable compact passes before generating all in-betweens.

## Paint a complete guide, then repair reusable parts

A later unarmed test used a licensed animated 3D character solely as a motion control. Appearance came from a separately generated original character. Eight actual source phases, sampled at equal intervals, supplied the pose sheet; a ninth cell repeated phase zero as an excluded return witness. The 3D source, camera, action, authored arm/head changes, fractional sample times, appearance reference and literal image prompt were retained separately. The control's legs/body remained from the licensed action. This is an authored experiment, not evidence of a private PixelLab backend.

1. Inspect the actual guide before generating paint. Freeze camera and common framing. State which control anatomy differs from the desired character, and whether the guide is a motion reference or a claimed exact geometry match.
2. Generate the whole pose set with the guide and appearance reference together. Check both opposing contacts, both passing phases and arm/leg opposition. Attractive individual drawings do not establish pose compliance.
3. Inspect the raw atlas before slicing. The test's generated rows drifted upward. Uniform slicing cut a later row's hair across a cell boundary. An explicit common row extraction correction recovered the existing pixels; it did not fit each pose independently or invent missing paint. Keep raw slices, corrected windows and the excluded return witness.
4. Compare alpha choices on light, dark and saturated backgrounds. A tested alpha threshold is specific to that source. Preserve RGB and record boundary losses; do not inherit the threshold for another generator or illustration.
5. Assemble the complete timed cycle early. This test used eight holds of 5/32 seconds, matching its guide's 1.25-second cycle, plus an exact rational APNG and an actual decoded four-loop movie. The editable full-body framepaint project is not a persistent anatomical rig.
6. Diagnose part motion against the actual control. One painted near arm bent across the belt while its neighbors hung down. The guide showed a smooth, low hand arc. Repairing only three poses created a new entry/exit discontinuity, so the experiment expanded to one coherent eight-pose near-arm track. Semantic upper-arm, forearm and glove donors, visible attachment controls and explicitly authored joint/underlap pixels remained distinct. Preserve uncertainty about hidden anatomy.
7. Test reuse of stable appearance parts. One source-owned head plus an explicit bob track reduced face/hair shimmer without moving the body. A local attachment improvement does not approve the whole animation. Palette reduction is likewise a separate finishing experiment: compare native material/detail quality, preserve alpha and avoid dithering-induced temporal noise.
8. Recheck every predecessor/current pair, loop wrap and opposing pair on the final combined output. Bind candid review to the actual exported frames/movie. Keep editor exchange, rational clocks, source ownership and art acceptance as separate results.
