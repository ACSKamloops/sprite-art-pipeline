# Protected body paint, complete arm keys and local motion cleanup

Use this route when a detailed, internally coherent raster character is already available, but separated cutout limbs look broken or new video generation is unavailable. It is a tested compact-punch case, not a general animation-quality guarantee or a reconstruction of a vendor's private model.

Freeze the appearance, native body scale, camera, ground/render pivots, exact exposure clock and intended action first. Keep the approved art separate. A raised combat guard-to-guard jab has a different endpoint contract from idle-to-idle or a heavy stepped attack. Scope reviews accordingly; quiet legs alone are not an anatomical error.

Create motion guides independently from paint. This case tested both an explicit two-bone 2D guide and an actual Blender capsule/sphere proxy with fixed camera, foot anchors and authored torso rotation. A proxy supplies pose information, not the character's missing production geometry. The simple proxy guide was rendered locally; it did not use a local generative model. Paint-only generation used the available OpenAI ImageGen tool, not Google Imagen or a new H3 video call.

Generate several **complete arm drawings in neighboring-pose context**, rather than rotating separately clipped plate, sleeve and glove fragments into a final sprite. Preserve a strong fixed body outside an explicit arm mask. Ask for distinct chamber, extension, contact and early recoil, plus stable shoulder origin, closed glove and guarding hand. A pose prompt does not prove compliance: the model made an intended bent half-extension comparatively straight. Review the produced silhouette and connected metal/cloth volumes.

Save the literal tool prompt separately from the longer authoring brief if they differ, references and exact generated bytes. Avoid these demonstrated shortcuts:

- A horizontal upper/lower split clipped relaxed gloves even though the high-guard strike looked correct. Check all endpoints before masking.
- Fixed distal soles pasted over moving shins created a9px calf/cuff shear. Connected alpha and fixed toe pixels did not establish continuous anatomy.
- Separately assembled source arm pieces produced gaps, a detached107pixel glove, and bad material overlaps despite correct bone math.
- A whole connected arm affine kept connectivity but flattened the fist into a wedge. Source-pixel ownership did not preserve shape. It was rejected before review.
- Restoring more poses from a full-body generated sheet introduced an abrupt torso/guard occlusion and boot relocation. Do not assert an impossible arm swap when legitimate occlusion remains plausible.
- A stronger shoulder/head response was investigated separately. A user choosing the compact jab does not authorize silently replacing it with the heavier variant.
