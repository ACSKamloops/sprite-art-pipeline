# Emberwake: The Hollow Bell
A small complete top-down action RPG, original art and setting. Village + forest + ruined shrine, three wards, final boss, ending; 10-minute intended play. Chrono Trigger informs camera/world layering, not copied assets. Four cardinal facings, unarmed close attack, firebolt, frost nova, dodge, interact, healing, pause/help, death/retry. Original blue/silver brown-haired hero. No API required to run.

Visual thesis: amber lanterns and carved jade ruins in a cool moss forest, warm handcrafted sprite art, quiet village opening followed by readable magical combat.
Content plan: full-canvas world; sparse health/mana and objective HUD; compact contextual dialogue; map/controls on pause; title and ending screens.
Interaction thesis: restrained footstep/breathing animation, quick readable impact/telegraph/recoil, gentle camera follow with minimal configurable shake.

## Runtime contract (Godot 4.7.2, Compatibility, viewport 960x540)
