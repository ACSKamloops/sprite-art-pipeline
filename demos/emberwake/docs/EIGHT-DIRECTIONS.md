## Direction and action behavior

W+D selects NE, S+D SE, W+A NW and S+A SW. Diagonal movement is normalized, with
the same speed as cardinal movement. The selected eight-sector combat aim is
locked for a committed strike/cast/dodge. Releasing movement keeps the facing.
Turning while walking preserves cycle phase, rather than restarting the gait.
Mouse aim uses the same eight sectors. Firebolts originate at each view's
measured painted glove while swept collision remains on the ground plane.
