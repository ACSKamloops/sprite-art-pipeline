# Retained-paint gait replay example

This fixture replays one Brann northeast walk from four retained native ImageGen keys, literal contact owners, frozen integer part maps and a real arm-edit journal. It does not infer a rig or synthesize new art. It also applies the separately recorded eleven-pixel production border cleanup and emits the conditional NW mirror. All generation was performed earlier with the built-in ImageGen tool; no model or credential is needed for replay.

From this folder, with NumPy 2.3.5 and Pillow 12.1.1 installed, use a fresh output:

```sh
python3 source-rebuild/rebuild.py --out /absolute/fresh/gait-replay
```

The bundled toolkit is a real dependency. The script checks source hashes, exact layered project preconditions, the real journal, all eight RGBA outputs and pinned-toolchain PNG bytes. Lossless gzip retains large journal/control data; it does not discard source pixels. Final baked frames are not reconstruction inputs. The semantic generation step is nondeterministic and is not claimed reproducible by this offline replay.

The existing raw whole-walk judgment is drawing 8.5, motion 8 and game use 8 for NE and its conditional NW mirror, from ordered stills and known holds. A separate exact-delta review found no meaningful visible change from the eleven NE border edits (seven changes after conditional mirroring). These are scoped case judgments, not acceptance of a new character, other actions, continuous human playback or physical foot contact. NW retains six faint alpha-1 border pixels; this fixture reports them and does not silently expand cleanup.

Use this to understand source ownership and replay. Supply new accepted paint, measured masks, anatomical keys, ordering, timing and reviews for another asset; this case's numeric coordinates and grades are not universal settings. The full native editor and Godot evidence remain in the project's brann-ne-gait-v1 and source-cel-preview-v12 packages.
