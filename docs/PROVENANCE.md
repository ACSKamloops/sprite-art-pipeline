# Provenance and transfer boundaries

[IMPORT-MANIFEST.json](../provenance/IMPORT-MANIFEST.json) binds each selected file
to its original local path, source bytes/hash and imported hash. It records source
Git revisions/status and Markdown links changed to included relative targets.
Some original notes retain local case/evidence paths intentionally.

The selection includes all four installed pipeline skills, the complete tracked
PixelLab local-workbench snapshot, runtime Emberwake source/assets plus selected
documentation, authoring programs, original generic-hero walk evidence, reviewed
PixelLab handoff notes and latest Lyra repair.

The later [current-hero snapshot](../examples/current-hero/package/SNAPSHOT.json)
is a separate post-consolidation import of selected generated character outputs.
It pins the local package-v4 library, keeps all136 selected bindings/561 exposures
and excludes18 unselected alternatives. Complete clip folders are byte-identical;
the selected-only library and viewer navigation are explicitly adapted.
[FILESET.json](../examples/current-hero/package/FILESET.json) pins its distributed
files. This snapshot does not import authenticated research captures or source
game assets, and it needs no original absolute source path at runtime.

The imported method programs are not all independently portable executables.
Portable toolkits/examples have their own commands and fresh tests. Historical
programs retain source paths and dependencies; use them as evidence or adapt them
explicitly rather than blindly executing old producers.

- [Local Emberwake source/evidence inventory](../provenance/LOCAL-ONLY-EMBERWAKE.json)
  records omitted historical art/data required by some rebakes.
- [Local evidence directory index](../provenance/LOCAL-EVIDENCE-INDEX.json) locates
  the larger original experiments on the current machine. It grants no recursive
  sharing approval and does not copy the contents.
- [Reviewed PixelLab notes](../research/pixellab-investigation/REVIEWED-HANDOFF-FILES.json)
  identify the authored handoff subset. Authenticated captures and external
  dependencies are not imported by listing them.

No ROM, extracted source-game artwork, browser profile, private REA/session archive,
credential store, unsanitized HAR or personalized extension is part of the
selection. Original/generated art examples and source-bound recovered client
subsets are retained with their actual provenance and existing notices. This is
a public repository; no blanket license is inferred for upstream material.

No temporary Git worktree was created for this consolidation. The new
`/home/astra/projects/sprite-art-pipeline` checkout is the primary repository for
this handoff and remains for continued development. Existing source repositories,
unfinished review checkouts and live local viewers are preserved. No source
workspace was removed or reset by the consolidation.
