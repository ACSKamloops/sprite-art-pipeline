# Sprite art pipeline

Read README.md, docs/STATUS.md, docs/REQUIREMENTS.md and docs/METHODS.md first.
For the transferable AI task message, read docs/MESSAGE-FOR-AI.md; use
docs/AI-HANDOFF.md for the detailed continuation guide.
This is the consolidated methods repository. Historical source checkouts and
local-only evidence are recorded in provenance/; do not alter them during tests.

Preserve the exact user-approved originals beside experiments. New art, rig
guides, source-part warps, pixel edits and retiming are different operations;
record the actual operation and provider. The current authoring preference is
built-in OpenAI ImageGen plus deterministic/manual editing. H3 and local
generative-model execution are disabled for current production unless the user
changes that instruction. Historical H3 code and results are retained evidence.
Never launch paid/provider jobs as an installation, CI or verification step.

All requested directions/actions need their own coverage and review states.
Passing files, hashes, masks or engine tests does not establish art quality.
Review every frame, predecessor/current pair and wrap/recovery at intended scale;
normal-speed human playback rejection overrides earlier still-frame scores.
Keep numerical judgments scoped to the actual source hash and action/view.
Do not claim continuous video perception from decoded stills or browser transport.
PixelLab private models, weights and hidden server methods remain unavailable.

Use fresh output directories and explicit masks/journals. Retain original paint,
ordered references, actual prompts, timing, pivots, equipment ownership and input
hashes. No per-frame automatic fitting or recentering. A flat sprite does not
recover unseen anatomy or a 3D rig. Weapon swaps need compatible motion and
measured hand/occlusion tracks, not a blade pasted onto a punch.

Before edits, inspect git status. If agents are authorized, use exclusive
worktrees and file ownership; no concurrent writers in this checkout. Clean up
only completed temporary worktrees after preserving their unique work and refs.
Do not copy ROMs, source-game assets, credentials, browser profiles, private
captures or personalized extensions into this repository. Check staged content
with scripts/check_repository.py before publishing.
